# davejoem.github.io

Personal portfolio and founder page for **Dave Joe M** — founder of [Infiforge Technologies](https://davejoem.github.io/), a Kenyan software and technology solutions company.

## What's Here

- Single-page portfolio (HTML + CSS + vanilla JS, no build step)
- Dark and light theme toggle with system-preference default
- Responsive: mobile, tablet, desktop
- Self-hosted fonts: Libre Baskerville + Montserrat
- GitHub Pages native — just push to `master`

## Sections

Hero · About · Skills · Portfolio (12 Infiforge services) · Experience · Stats · Contact

## Stack

- **HTML/CSS/JS** — no frameworks, no dependencies
- **Fonts** — self-hosted Libre Baskerville (serif display) + Montserrat (sans UI)
- **Assets** — SVG monogram, generated OG image and Apple touch icon
